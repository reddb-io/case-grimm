# Tale Reader

This is the editorial side of the showcase. Start with the curated gold text,
then pivot into source editions, side-by-side comparison, graph facets, and
branch records without losing the reading context.

The reader intentionally keeps three layers separate:

- **Gold**: the canonical 206-tale collection used by the showcase.
- **Silver**: original extracted book tales used for provenance and comparison.
- **Graph facets**: structured lenses such as world laws, moral regimes,
  characters, locations, Propp-like events, and branch metadata.
